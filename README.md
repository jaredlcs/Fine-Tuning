# Fine Tuning

### Model: deberta-v3-base-prompt-injection

### Datasets:
- https://huggingface.co/datasets/xTRam1/safe-guard-prompt-injection
- https://huggingface.co/datasets/reshabhs/SPML_Chatbot_Prompt_Injection

### Goal:
Use deberta-v3 on both datasets and fine-tune model.

### Workflow Ex:
1. Use deberta-v3 on safe-guard-prompt-inject and evaluate
2. Fine tune deberta-v3 on safe-guard-prompt-inject and evaluate
3. Use deberta-v3 (fine-tuned) on SPML and evaluate
4. Fine tune deberta-v3 on SPML and evaluate
